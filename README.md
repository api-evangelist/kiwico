# KiwiCo

KiwiCo, Inc. is a direct-to-consumer education company headquartered in Mountain View, California, founded in 2011 by Sandra Oh Lin. KiwiCo designs and ships hands-on STEAM project kits — branded as crates — on a monthly subscription for every age from infants through teens and adults, plus single-purchase kits through its online store. A KiwiCo Education division supplies the same kits and NGSS-aligned lesson guides to schools, homeschools and camps.

**No public developer program.** As of the 2026-07-19 enrichment pass KiwiCo publishes no developer portal, API documentation, OpenAPI definition, SDK, CLI, MCP server or webhook surface, and no `/.well-known/` discovery documents on any host. The `api.kiwico.com` hostname serves consumer storefront and lesson-guide content, not a programmable API. This repo therefore carries verified company identity and public web properties only.
